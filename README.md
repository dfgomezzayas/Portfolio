# 🚀 Daniel Gómez — FullStack Developer Portfolio

This is my personal portfolio built with **Next.js**, focused on performance, scalability, and internationalization.

---

## 🧠 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Internationalization:** next-intl
- **Styling:** Tailwind CSS
- **Backend (separate projects):** FastAPI
- **Deployment:** Vercel (recommended)

---

## 🌍 Internationalization (i18n)

This project uses **next-intl** for a scalable and SEO-friendly i18n setup.

### Features:

- 🌐 Multi-language support (Spanish 🇪🇸 / English 🇺🇸)
- 🔗 Locale-based routing (`/es`, `/en`)
- ⚡ Server-side translations
- 🧠 SEO optimized with `hreflang` and localized metadata

---

## 🔍 SEO Optimization

The application is optimized for search engines with:

- Dynamic metadata per locale
- `hreflang` configuration for international targeting
- Open Graph & Twitter Cards
- Canonical URLs
- Semantic HTML
